# CodeFix 🚀

CodeFix is a cyberpunk-themed, gamified learning platform for mastering debugging. 
It features a Vanilla JS + Vite frontend and a Node.js + Express backend with an SQLite database.

## Prerequisites
Before you start, make sure you have **[Node.js](https://nodejs.org/)** installed on your computer.

## How to Run Locally

We have created an automated launcher to make running the project as easy as possible!

1. Unzip this folder on your Windows computer.
2. Double-click the **`start.bat`** file located inside the folder.
3. The script will automatically install all dependencies, boot up the database, and open the application in your browser!

*(Note: If Windows Defender shows a "Windows protected your PC" blue screen, click "More info" and then "Run anyway").*

**Troubleshooting:**
If the browser does not open or the script fails, ensure you have **[Node.js](https://nodejs.org/)** installed on your computer.


---

**Note:** If you ever want to clear the database and start fresh, you can simply delete the `backend/codefix.db` file. The server will automatically recreate it the next time you start it.
